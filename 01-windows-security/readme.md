# Windows Operating System Fundamentals and Security

Hands-on cybersecurity laboratory work focused on Windows 10 operating-system fundamentals, identity management, access control, privilege management, boot security, command-line administration, and security analysis.

This lab was performed as part of the **Cyber Security Skill Development Lab (2026–28)** during my **M.Tech in Cyber Security, Semester I** at **Defence Institute of Advanced Technology (DIAT), Pune**.

---

## 1. Objective

The objective of this laboratory was to develop a practical understanding of Windows operating-system fundamentals and security mechanisms using a controlled Windows 10 virtual-machine environment.

The lab focused on:

- Understanding the Windows boot process
- Understanding authentication and authorization
- Creating and managing local users and groups
- Comparing administrator and standard-user privileges
- Understanding User Account Control (UAC)
- Working with file and folder permissions
- Understanding NTFS access control
- Using Command Prompt and PowerShell for system administration and security analysis
- Identifying security weaknesses caused by excessive privileges and inappropriate permissions
- Understanding the principle of least privilege

---

## 2. Lab Environment

| Component | Configuration |
|---|---|
| Virtualization | Oracle VM VirtualBox |
| Operating System | Windows 10 |
| Architecture | 64-bit |
| Virtual CPUs | 2 |
| RAM | 4 GB |
| Virtual Disk | 50 GB VDI, dynamically allocated |
| Network | NAT |
| Command-Line Interfaces | Command Prompt, PowerShell |

The experiments were performed inside a virtual machine to provide an isolated and controlled environment for security-related configuration and access-control testing.

A VM snapshot was created before performing experiments so that the system could be restored to a known working state if required.
