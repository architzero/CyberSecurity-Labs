# Cybersecurity Learning

My hands-on cybersecurity learning journey during my M.Tech in Cyber Security at Defence Institute of Advanced Technology (DIAT), Pune.

This repository documents my laboratory work, practical exercises, security concepts, tools, experiments, and technical notes as I progress through cybersecurity.

## Topics Covered

- Operating System Security
- Linux Security
- Windows Security
- Access Control
- Authentication & Authorization
- User and Group Management
- File Permissions
- Privilege Management
- Networking & Network Protocols

## Laboratory Work

### 01. Windows Operating System Security
Hands-on work with Windows 10 covering:

- Windows boot process
- Authentication and authorization
- User and group management
- Administrator and standard-user privileges
- User Account Control (UAC)
- File and folder permissions
- NTFS access control
- CMD and PowerShell
- Security-relevant system analysis

### 02. Linux Operating System Security
Hands-on work with Kali Linux covering:

- Linux boot sequence
- Users, groups, UID and GID
- File ownership and permissions
- SUID, SGID and Sticky Bit
- Linux capabilities
- `sudo`, `su` and privilege management
- Bash and Zsh
- Process and service analysis
- Security-relevant Linux commands
- Network and system analysis
